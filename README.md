# My Flask Website

A simple and beginner-friendly website built using Python, Flask, HTML, and CSS.

## About the Project

This is my first Flask website project. It is created to learn web development using Python Flask and frontend technologies.

The website includes a simple homepage with a welcome message and a clean, modern design.

- Python
- Flask
- HTML5
- CSS3
- Git & GitHub

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Shreyanshnema44/my-flask-website.git
```

### 2. Open Project Folder

```bash
cd my-flask-website
```

### 3. Create Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate Virtual Environment

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install Flask

```bash
pip install flask
```

### 6. Run the Website

```bash
python app.py
```

Open your browser and visit:

http://127.0.0.1:5000
